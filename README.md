## 💻 Sobre o Projeto

Em aplicações financeiras, a precisão e a fiabilidade visual são inegociáveis. O Refund 2.0 é um *dashboard* desenvolvido para gerir pedidos de reembolso, combinando uma arquitetura React robusta com validações de esquemas de dados estritos.

> **Nota:** Adicionar Screenshot do painel financeiro a funcionar. 
> `![Refund Dashboard](./caminho-para-imagem.png)`

## ✨ Principais Funcionalidades

- **Dashboard Analítico:** Visualização clara de dados e métricas financeiras.
- **Validação de Formulários Estrita:** Integração com bibliotecas de validação (como Zod) para garantir que valores monetários e descrições estão perfeitamente formatados antes da submissão à API REST.
- **Integração de APIs REST:** Arquitetura preparada para consumo de dados externos de forma assíncrona, mantendo o *feedback* visual ativo (Loading states, Error boundaries).
- **Performance de Renderização:** Otimização da árvore de componentes para evitar re-renderizações desnecessárias ao lidar com grandes listas de transações.
